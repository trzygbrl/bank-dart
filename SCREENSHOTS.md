# Simple Bank Screenshot Guide

Capture each canonical screenshot from the desktop app at **1000 × 680 px**
with the window unobstructed and no dialogs or menus covering the view. Save
the PNGs under `docs/screens/`. The screenshots are manual visual evidence;
they are not generated by widget tests.

## Capture procedure

1. Run the app with `flutter run -d windows` (or `-d macos` / `-d linux`).
2. Set the app window to 1000 × 680 px and ensure the entire application is
   visible.
3. Follow the setup for each image below, then capture the full app window as a
   PNG at native resolution. Avoid including other windows or desktop overlays.
4. Save the exact filename listed below. Confirm the sidebar, content, text, and
   colors are readable before accepting the capture.

| File | View and setup | Required visible content |
|---|---|---|
| `docs/screens/balance.png` | Capture immediately after a fresh launch. | Check Balance view, ₱5,000.00 balance card, and startup caption. |
| `docs/screens/deposit_error.png` | Open Deposit Money, enter `0`, and submit. | Deposit form with the inline “Amount must be greater than zero.” error and retained input. |
| `docs/screens/withdraw_success.png` | Open Withdraw Money on a fresh account, enter `1000`, and submit. | Withdrawal success message, cleared field, and updated available balance. |
| `docs/screens/history.png` | From a fresh account, perform at least five successful transactions, then open Transaction History. | Header and at least five chronological rows, alternating row fills, and Deposit/Withdrawal label colors. |

Use the screenshot files with `PARITY.md` for Java-Dart side-by-side review.
Do not replace the PRD’s wording or design tokens to improve a screenshot.
